# Linear Programming Solver

A Python application for solving linear programming problems with an intuitive graphical user interface built using Flet.

## Overview

This project provides a tool to solve linear programming optimization problems. Users can input objective functions and constraints, and the application will calculate and display the optimal solution.

## Features

- **Linear Programming Solver**: Solves LP problems using optimization algorithms
- **Graphical User Interface**: Built with Flet for a modern, cross-platform UI
- **Problem Input**: Easy-to-use interface for defining objective functions and constraints
- **Solution Display**: Clear visualization of results and optimal values

## Requirements

- Python 3.8 or higher
- Flet
- scipy (for optimization)
- numpy (for numerical computations)

## Installation

1. Clone the repository:
```bash
git clone <repository-url>
cd IO-Project
```

2. Install dependencies:
```bash
pip install -r requirements.txt
```

## Usage

Run the application:
```bash
python main.py
```
